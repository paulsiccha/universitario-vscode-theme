# Garra Crema v1.0.0

## 🚀 Installation

### VS Code
1. Download the `.vsix` file from the Assets section below
2. Open VS Code
3. Open the Command Palette: `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux)
4. Type and select "Extensions: Install from VSIX..."
5. Select the downloaded file
6. Activate the theme: `Cmd+Shift+P` → "Preferences: Color Theme" → "Garra Crema"

### Terminal
```bash
code --install-extension garra-crema-theme-1.1.0.vsix
```

### Cursor
Same installation process as VS Code.

## ✨ Features

- **Dark theme** inspired by Universitario de Deportes colors
- **Optimized syntax highlighting** for JavaScript, TypeScript, and other languages
- **Custom file icons** for the explorer
- **High contrast** for better readability
- **Compatible** with VS Code and Cursor
