Instalación

Listo en segundos

Instalación directa, sin configuraciones complejas

Descargar el archivo .vsix

Descarga la última versión desde GitHub Releases

Abrir VS Code o Cursor

Asegúrate de tener el editor abierto

Abrir la paleta de comandos

Presiona Cmd+Shift+P (Mac) o Ctrl+Shift+P (Windows/Linux)

Instalar desde VSIX

Escribe y selecciona "Extensions: Install from VSIX..."

Seleccionar el archivo

Elige el archivo .vsix que descargaste

Activar el tema

Presiona Cmd+Shift+P → "Preferences: Color Theme" → Elige tu variante
